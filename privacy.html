3. General Information

When you visit this website, personal data may be processed. Personal data is any information that can identify you as an individual, such as your IP address. Data is processed only to the extent necessary to operate the website and to respond to your direct inquiries. The legal basis is generally Art. 6 (1) (f) GDPR (legitimate interest in operating a functioning, secure website) and Art. 6 (1) (b) GDPR for pre-contractual or contractual communication.

4. Hosting (Vercel)

This website is hosted by Vercel Inc., 440 N Barranca Avenue #4133, Covina, CA 91723, USA. When you access the site, Vercel processes technical data necessary to deliver the content, including:

  • IP address
  • Date and time of access
  • Browser type and operating system
  • Referrer URL
  • Volume of data transferred

This data is processed on the legal basis of Art. 6 (1) (f) GDPR (legitimate interest in providing a secure, stable website). A Data Processing Agreement according to Art. 28 GDPR is in place with Vercel.

Vercel is based in the United States. Data transfers to the USA are covered by Vercel's certification under the EU-U.S. Data Privacy Framework (DPF), which provides an adequate level of data protection according to Art. 45 GDPR.

Vercel's privacy notice: vercel.com/legal/privacy-policy

5. Web Analytics and Speed Insights (Vercel)

This website uses two privacy-focused services provided by Vercel Inc.: Vercel Web Analytics and Vercel Speed Insights. Both services are cookieless and do not collect or store any personally identifiable information.

Web Analytics collects the following anonymized data for aggregated traffic statistics:

  • Page views
  • Country (derived from IP address; the IP itself is not stored)
  • Browser type and operating system
  • Referrer URL
  • Device type

Visitors are identified using a daily-rotated hash that is automatically discarded after 24 hours. No cross-site or long-term tracking takes place.

Speed Insights collects anonymized performance data to measure and improve the website's loading speed and user experience, including:

  • Core Web Vitals (Largest Contentful Paint, Interaction to Next Paint, Cumulative Layout Shift)
  • Page URL and route
  • Browser, device type, and connection type

No personal identifiers are collected. The legal basis for both services is Art. 6 (1) (f) GDPR (legitimate interest in understanding aggregated website usage and improving website performance).

For details, see Vercel's documentation:

  • Web Analytics Privacy
  • Speed Insights Privacy
